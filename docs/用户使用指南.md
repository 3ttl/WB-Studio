# WB Studio 用户使用指南

[返回项目首页](../README.md) · [v0.9.1 更新说明](v0.9.2更新说明.md)

软件支持收藏总览，可按实验、蛋白查看收藏选框截图并多选导出 PDF。工作台预览框固定为 16:9，预览区与显示调节区按 3:2 分配宽度。关联拍摄图按比例沿用分析图条带位置；原图、选框和定量数据保持独立。

v0.9.1 在工作台“灰度与比值”表格中增加了**灰度柱状图**列，位于校正信号和分母信号之间。每个泳道一条横柱，同一选框共用线性刻度；柱长以测得的背景校正信号为依据，悬停可查看数值。未测量或测量过期显示“—”，零值无柱长，负值向零线左侧显示。切换选框或重新测量后自动更新，不受显示对比度影响；复制当前结果仍输出原有数值列。

**用于 Western Blot 图片管理、条带定量、统计分析和实验资料导出的 Windows 桌面软件。**

当前版本：**v0.9.2 · 本地测试版**

WB Studio 将原始图片、蛋白与实验标签、选框、泳道、内参对应关系和统计组合放在同一个工作流程中，减少反复查找图片、手工整理灰度值和拼排资料的工作。

图片在本机读取和处理，原始文件保持不变。标注、绑定关系和使用设置单独保存在本地。

## 能做什么

| 页面 | 主要功能 | 可以得到什么 |
|---|---|---|
| **条带工作台** | 批量导入图片、筛选排序、日期折叠、标签与分组预设、旋转和显示调整、自动泳道识别、ImageJ 测量、内参绑定、双条带比值、收藏 | 每个泳道的灰度测量、背景校正信号及比值 |
| **统计分析** | 从共用图库选择图片，自动读取工作台比值，按组整理独立样本并计算，兼容同一张膜包含多个生物样本 | 可粘贴到 Excel 的数据与结果、可复用的图片组合、关联原图 ZIP |
| **内参调齐** | 同时查看多个内参的条带图和泳道柱状图，按对应样本汇总信号，估算再次上样体积 | 各样本建议上样量、补加 1× SDS 体积和最终总体积 |
| **收藏总览** | 自动显示收藏图片的所有选框截图，按实验与蛋白分层，折叠、拖动排序、勾选导出 | 保留工作台显示效果的条带总览，直接进入共用 PDF 导出流程 |
| **原始数据导出** | 按实验和蛋白整理图片组合，调整顺序，将化学发光图、背景图和合成图排成三列 | 白底、8-bit 图像的 PDF 资料报告，可附来源与显示参数清单 |

## 安装与启动

### 运行环境

- Windows 10 / Windows 11，64 位。
- .NET Framework 4.7.2 或兼容的更高版本。
- Microsoft Edge WebView2 Runtime。
- 发布包已附带 Python、ImageJ 和私有 Java 运行时，无须自行安装 Python、Java 或 Fiji。

### 启动方法

1. 将发布压缩包**完整解压**到一个可写的本地文件夹，例如 `D:\WB_Studio`。
2. 双击 **`WB Studio.exe`**。
3. 保留程序旁的 `app`、`runtime`、DLL 和配置文件，不要只复制 exe。

程序运行时会在自身目录下建立 `data` 文件夹，用来保存图库索引、标注、设置和缓存。请将程序与 `data` 放在本地目录，不要放进 OneDrive 同步目录运行；OneDrive 中的原图可以作为只读来源。

## 第一次使用：先跑通示例

软件自带 6 张合成 TIFF：3 张 P62 目的条带图、3 张对应的 ACTB 内参图，每张有 4 个泳道。

1. 在条带工作台点击 **“自带测试示例”**。
2. 依次打开 3 张 ACTB 图片，核对选框后分别点击 **“确认并测量”**。
3. 再打开 3 张 P62 图片，分别点击 **“确认并测量”**。示例已预设目的图与内参的对应关系。
4. 查看工作台中的逐泳道比值。
5. 进入 **“统计分析”**，选择 3 张 P62 图片及对应选框，核对每组 3 条有效比值，点击 **“生成比较”**。
6. 尝试 **“复制数据到 Excel”**，在 Excel 中粘贴。
7. 填写组合名称，点击 **“保存组合”**，再到 **“原始数据导出”** 预览并导出 PDF。

示例用于熟悉操作，不是实验数据，不能用于科研结论。自带示例未附背景图和合成图，PDF 中对应位置会显示缺失说明。

## 1. 管理实验图片

### 导入、筛选与查找

点击 **“添加文件夹”**，选择原始图片目录。软件会递归扫描子文件夹，并显示导入进度和当前处理的文件。

- 按文件名搜索，按图片类型、文件格式、蛋白名称和实验组别筛选；这四栏可下拉勾选多项，同栏任意匹配、跨栏同时满足。
- 使用一级、二级排序，例如先按文件修改时间排序，再按文件名排序。
- 日期目录支持折叠、展开，也可使用 **“全部展开”** 和 **“全部收起”**。
- 工作台左右各约占一半宽度，可以独立滚动。
- 点击图片卡片右侧的 **ⓘ**，查看文件路径、尺寸、位深、格式、大小和时间记录。
- 点击工作台图片标题旁的 **“收藏”**，便于随后在统计图库中筛选。

### 图片分类规则

软件按 Bio-Rad 文件名**最后一对括号中的拍摄模式**识别图片类型。

| 文件名中的模式 | 图片类型 |
|---|---|
| `Chemiluminescence` | 化学发光图 |
| `Composite` | 合成图 |
| `Amido Black`、`Stain Free`、`Colorimetric` 等其他模式 | 背景图，并保留具体模式名称 |
| 没有可识别的末尾模式括号 | 未识别类型 |

图片类型提供“化学发光 · 16-bit 图”“化学发光 · 8-bit 图”“合成图”“背景 · 16-bit 图”“背景 · 8-bit 图”和“未识别类型”。16-bit 化学发光图统一显示，包含名称符合 `(Chemiluminescence).raw16` 规则的分析原图和其他 16-bit 化学发光图。

类型、格式、蛋白、组别四栏均可勾选多项；例如同时勾选化学发光 8-bit 和 16-bit 即可查看两类图，无需重复的汇总选项。点击“全部”取消该栏限制。图片能否定量仍根据实际像素格式判断。

主要支持 TIFF、PNG、JPEG、BMP 及内容为受支持图像的 `.raw16` 文件，不保证读取任意无头 RAW 数据。定量要求是**单页、单通道、8-bit 或无符号 16-bit 灰度图**；RGB、调色板、多页 TIFF 等图片可用于支持范围内的预览，但不能直接定量。JPEG 为有损格式，分析时优先使用无损原图。

### 日期与文件夹组织

日期分组只读取**图片直接所在文件夹名称中的完整年月日**。建议将同次拍摄的关联图片保存在同一日期文件夹中，例如：

```text
WB_images/
└─ 2026-09-06/
   ├─ Exp01_P62_R1(Chemiluminescence).raw16.tif
   ├─ Exp01_P62_R1(Amido Black).tif
   ├─ Exp01_P62_R1(Composite).tif
   └─ ...
```

如果图片实际位于 `2026-09-06/未命名/`，其直接父文件夹是“未命名”，因此会归入**未知日期**。软件不会从上层目录、文件名、TIFF 内部时间或文件修改时间猜测分组日期。导出时间缺失时，按该字段排序会将缺失项放到后面。

### 并排显示与定量设置

选中图片后，条带预览框固定为 **16:9**；预览区与右侧显示调节区按 **3:2** 分配宽度。显示调节包括原始灰度直方图、低值、高值、伽马、显示反相及自动对比度。拖动滑块即可同时观察图像变化；工具栏的“显示调整”可以收起或展开侧栏。放大、缩小、自动聚焦、全图显示和 Ctrl + 滚轮保持可用。

ImageJ 的分析位深、信号极性与后台映射最小/最大值集中在图像下方。展开“定量规则与注意事项”可查看背景选取和重新测量规则。前台显示调节不改变原始图片或测量值。

## 2. 设置标签与分组预设

图片的 **“实验”** 和 **“蛋白”** 使用可输入的单选标签：输入新名称后按 Enter，即可保存并加入下拉词库；已有名称可以搜索或直接选择，词库按名称排序。

实验、蛋白和分组预设的已有选项右侧均有 **⋯** 菜单，可**重命名**或**删除**。操作前会显示关联图片数量：实验和蛋白改名同步所有相关图片，删除会清空这些图片上的对应标签；删除分组预设只解除预设关联，保留已画好的泳道、组名和测量值，便于重新分组。已保存的图片组合保留原快照，若导出需使用新标签，请重新保存对应组合。

组别通过 **“分组预设”** 管理：

1. 点击 **“设置预设”**，输入预设名称。
2. 每一列为一个实验组，直接编辑组名；每一行为一种处理，编辑处理名称并勾选对应组合。
3. 新预设默认 **4 个组、2 项处理**。每组下方可填写**样本数（泳道）**，默认 1；可按需要增减组别和处理。
4. 保存后，在图片的下拉栏中选择该预设。
5. 当前图片的选框泳道数会同步为**所有组样本数之和**，组名按列顺序和每组样本数依次展开。每张图可包含不同组的多个样本，单个选框最多 96 个泳道。

应用后请核对实际上样顺序。修改预设不会自动改动其他已经应用该预设的图片，需要在对应图片上重新选择。泳道数发生变化时，须重新核对位置、测量并检查内参映射。

**生物样本 ID 为选填**。它用于识别不同图片中同一个真实样本，不能用组名代替。配对分析还需要填写 Pair ID；分组预设中的处理勾选也不会自动替代 Two-way ANOVA 的因素设置。

### 同一张膜上放两组、每组三个生物样本

例如实际泳道顺序是 `对照1、对照2、对照3、实验1、实验2、实验3`：

1. 新建两个组，名称为“对照组”和“实验组”，两组的样本数都填 **3**，保存预设。
2. 在目的图和对应内参图上选择该预设。矩形框自动设为 **6 个泳道**，前 3 个组名为“对照组”，后 3 个为“实验组”。
3. 框选、识别并核对实际六条条带，完成两张图的测量；逐泳道确认内参对应关系。
4. 进入统计分析，**只选择这一张目的图及其选框**。软件导入六个独立的目的/内参比值，按组形成两列、每列 3 个值，满足条件后按当前所选方法自动生成比较。
5. 如需留档，保存这一个图片组合即可，导出时不会把同一张膜重复三次。

若实际按 `对照1、实验1、对照2、实验2、对照3、实验3` 交错上样，请在泳道表中逐项修改组别为实际顺序。样本数设置只定义布局，**不会生成样本 ID，也不会把技术重复转为生物学重复**。只有来自三个独立生物样本的泳道才构成每组 n=3；同一份样本重复上样或重复曝光不能据此增加生物样本数。

## 3. 在条带工作台完成定量

### 调整观看范围并框选

1. 打开图片，用辅助线和 **0.1°** 步长旋转校正条带方向。
2. 必要时使用 **“自动对比度”**，或拖动低值、高值、伽马滑块调整显示。
3. 使用 **“画矩形”** 框住一排条带，再点击 **“自动识别泳道”**。
4. 核对每个候选条带的位置、宽高、数量和组别。识别不准时，可拖动选框边角调整，也可手工修正泳道。
5. 选择分析位深、后台映射范围和原始信号极性，点击 **“确认并测量”**。

各类图片默认自动聚焦至条带区域约占编辑区宽度 70%。没有自身选框的关联背景图、合成图和 8-bit 化学发光图会优先沿用同次拍摄分析图的位置；无关联时尝试自身定位。手动视图会保留，可点击“自动聚焦条带”恢复自动模式。

自动识别允许先画一个较宽松的粗框，但仍需要人工核对。它使用图像处理方法寻找候选条带，不是 AI 识别，也不会把简单均分当成成功识别。

预览支持 **＋ / −**、**Ctrl＋鼠标滚轮**、**“自动聚焦条带”** 和 **“显示全图”**。这些操作改变观看范围，不改原始文件或选框坐标。原始灰度直方图支持线性和对数纵轴。

### 目的蛋白 / 内参

1. 先完成目的图和对应内参图的选框与测量。
2. 在目的选框下点击 **“从左侧选择内参”**。
3. 从图库选择内参图片，再选择内参选框。
4. 逐一核对目的泳道与内参泳道的对应关系，并确认绑定。
5. 查看自动更新的逐泳道比值和结果图；可点击 **“复制当前结果”**。

每个目的选框可以单独绑定一个内参选框。比值使用背景校正后的信号：

```text
目的蛋白 / 内参 = 目的条带校正信号 ÷ 对应内参校正信号
```

### 双条带比值

切换到 **“双条带比值”**，分别框选并测量两个条带区域，再指定分子 A、分母 B，选择 **A/B** 或 **A/(A+B)**，点击 **“计算比值”**。

修改公式、选框或测量后，需要重新计算。分子、分母的泳道必须对应同一样本；有效比值还要求校正信号为正、两边分析口径一致。

### ImageJ 测量与显示调整的区别

本版内置实际 **ImageJ 1.54q**，用于分析副本的位深转换、旋转和矩形像素统计，可选择 **“8-bit 兼容模式”** 或 **“原始位深”**。显示用的对比度、伽马和反相不会写入定量像素。

背景校正采用 WB Studio 的固定规则：每个泳道矩形**顶部 2 行与底部 2 行**作为背景，这 4 行不计入中间信号区，因此选框高度至少为 5 px。请让背景行落在合适的背景位置。

ImageJ 负责像素统计；自动泳道检测、背景区域选择、内参映射和统计检验由 WB Studio 实现。本版不是 ImageJ Gel Analyzer 的轮廓峰面积流程，也未提供 rolling-ball 背景扣除。改变选框、旋转、分析位深、映射范围或信号极性后，需要重新测量。

## 4. 进行重复样本统计

1. 进入 **“统计分析”**，从左侧共用图库筛选实验、蛋白或收藏状态。
2. 选择要分析的图片；右侧以三列卡片显示，每张图片选择一个明确的选框。既支持三张膜各提供每组一个样本，也支持一张膜提供各组三个样本。
3. 软件自动读取工作台已经计算好的有效比值。需要更新时点击 **“刷新工作台比值”**。
4. 核对 **“当前实验”**、**“蛋白 / 比值来源”** 和组别，并为每组选择 **至少 3 条有效比值**。
5. 选择 **“原始比值”**，或选择 **“相对对照组均值”** 并指定对照组。
6. 选择统计方法和比较范围。有效记录完整且方法条件满足后，软件自动核对来源并生成比较；也可点击 **“生成比较”** 手动重新计算。更换图片、选框、分组或计算参数后会清除旧结果并重新核对。

数据表旁显示**均值 ± SD 和单个数据点**。可分别使用 **“复制数据到 Excel”**、**“复制来源明细”** 和 **“复制结果”**，再粘贴到 Excel。当前采用剪贴板表格复制，不直接生成 `.xlsx` 文件。

| 方法 | 当前提供的结果与要求 |
|---|---|
| Welch t · 两两比较 + Holm | 选定组对的独立样本比较及 Holm 校正 |
| 单因素 ANOVA + 预设比较（Holm） | 总体检验及所选组间比较 |
| 配对 t · 完整 Pair ID | 仅两组；Pair ID 须完整、唯一且一一对应 |
| 精确置换 · 均值差 + Holm | 独立样本均值差的精确置换比较及 Holm 校正 |
| Two-way ANOVA · 双因素 | 因素 A、因素 B 及 A×B 交互作用检验 |

Two-way ANOVA 需要填写两个因素及各组对应水平，所有因素组合完整且每格重复数相同。当前仅支持普通独立样本的平衡设计，**不支持重复测量、不平衡设计或混合效应模型**；也不提供双因素事后两两比较或简单效应检验。其三个因素效应 P 值未自动进行多重校正。

生物样本 ID 留空可以生成比较，但实验、蛋白和组别必须填写完整。**三张图片不自动等于三个独立生物重复**，请按实际实验设计核对来源；同一张膜的重复拍摄不能直接当作新增生物重复。配对关系也不能按 Excel 表格行号推断。

### 保存图片组合

在统计页选好 **1–3 张不同图片及各自选框**，填写组合名称，点击 **“保存组合”**。以后可从下拉栏恢复图片、选框和分析范围。组合的图片张数与生物样本数分别记录：一张六泳道膜可以提供两组各三个独立样本。

组合是后续 ZIP 和 PDF 导出的来源。图片选择或相关分析信息改变后，需要再次保存组合；普通标签、选框和内参关系的自动保存不能替代这一步。

## 5. 根据多个内参估算再次上样量

1. 进入 **“内参调齐”**，按蛋白名称筛选，勾选一个或多个已完成有效测量的内参选框。
2. 在右侧查看实际条带图和逐泳道柱状图，勾选纳入计算的泳道。
3. 核对这些图片来自**同一批对应样品**，且同一样本在不同内参图中的原上样体积相同。
4. 选择汇总方法，输入实际原上样体积和最终总体积，确认样品与补液均为 **1× SDS** 体系。
5. 点击 **“计算上样方案”**，查看并复制结果到 Excel。

默认方法为 **“各内参归一化后取均值”**：每张内参图先将各泳道信号除以纳入泳道的均值，再对同一样本的多个内参相对值取平均。

```text
建议样品体积 = 实际原上样体积 ÷ 合并后的相对信号
补加 1× SDS 体积 = 最终总体积 − 建议样品体积
```

例如原上样 10 µL，合并相对信号为 1.25，则建议样品体积为 8 µL；若最终总体积设为 12 µL，补加 4 µL 的 1× SDS。最终总体积留空时，软件取各样本建议体积的最大值。

完整样本 ID 用于跨图自动对应；全部未填 ID 时，需要核对并确认相同原始泳道编号代表同一样本。只填写部分 ID、重复 ID 或各图纳入的样本集合不同，会阻止合并。

另一种 **“原始校正灰度直接取均值”** 仅适用于同一内参蛋白、同一测量口径和可直接比较的检测条件。此模块提供体积估算，不保证真实条带一定调齐；应核对信号未饱和、内参稳定及样本条件。它不用于原始裂解液与浓缩 SDS 缓冲液的配制。

## 6. 导出 PDF 和原始图片包

### 原始数据 PDF

1. 先在统计页保存图片组合。
2. 进入 **“原始数据导出”**，左侧按**实验 → 蛋白 → 图片组合**显示。
3. 勾选需要的实验，折叠目录或拖动实验、蛋白调整顺序；同一蛋白有多个组合时选择其中一个。
4. 设置页面参数，核对右侧预览及关联图片。
5. 点击 **“导出 PDF”**，等待生成，在 Windows 保存对话框中选择位置。

| 参数 | 可选内容 |
|---|---|
| 文档标题 | 自定义报告名称 |
| 纸张与方向 | A4 / A3，纵向 / 横向 |
| 每页蛋白数 | 1 个或 2 个 |
| 图片大小 | **完整图片** / **放大条带 · 50%** |
| 背景及合成图显示 | 原始范围或自动对比度，输出 8-bit 灰度 |
| 说明信息 | 原始文件名、图片来源清单 |

每个实验从新页开始。每个蛋白占一个行块，三列分别是 **Chemiluminescence（化学发光图）**、**Background（背景图）**、**Merge（合成图）**，每列按组合中的实际图片顺序排列。版面保留最多三个图片位置，只有一张图时只显示一套关联图片，其余位置留白；“图片 1”等标记表示来源图顺序，不表示生物重复编号。

PDF 使用白底，不添加表格底色，三类图片均输出为 **8-bit 灰度**。化学发光图使用工作台当前已保存的对比度、伽马和反相；背景图与合成图单独设置显示范围。

**50% 的含义**：以所选矩形框的宽度和中心为依据，使框宽约占每列图片显示框的 50%。三类图片同步等比缩放，保留显示框内的周围画面，不把图片裁成只剩矩形框的窄条；超出显示框的部分暂不显示，图外区域留白。需要所有边缘时切回“完整图片”。预览和 PDF 使用相同的显示范围。

关联图片必须在**同一直接父文件夹**中，基础文件名相同，仅末尾拍摄模式不同。唯一候选自动匹配，多个候选可自行选择；缺失图片显示占位说明。不同分辨率的关联图会同步缩放，各自保持宽高比。

只调整化学发光图的显示对比度时，保存后更新预览即可；如果改变了选框、样本信息或定量条件，则须先完成必要的重新测量，并重新保存统计组合。

### 保留原文件的 ZIP

在统计页选中已保存组合，点击 **“导出组合文件”**，勾选需要的化学发光图、背景图和合成图，再点击 **“生成并保存 ZIP”**。

ZIP 保留所选图片的**原始文件字节**，并附来源清单。它与 PDF 的用途不同：PDF 用于阅读和排版展示，ZIP 用于交付所选原始图片。PDF 中的 8-bit 转换和显示调整不会写入 ZIP 中的原图。

## 7. 收藏总览与多选导出

1. 在条带工作台打开图片，设置实验、蛋白和泳道分组，调整显示效果并画好选框，然后点击 **“收藏”**。
2. 打开顶部 **“收藏总览”**。页面自动显示所有收藏图片中的每个矩形选框，不要求先测量或保存统计组合。一个图片有多个选框时会分别显示。
3. 一级标题是实验名称，下方按蛋白排列。蛋白名位于左侧、与该蛋白区域垂直居中；每行最多三张条带，多出的自动换行。
4. 每张条带上方显示泳道组名，优先按已识别泳道中心对齐，尚无识别位置时按泳道数均分。相同组的多个样本仍逐泳道标注；换行后重复显示组名，便于对照。较长组名可悬停查看。
5. 点击实验或蛋白前的箭头折叠／展开。拖动标题可调整同层级顺序，也可使用上下箭头；蛋白在所属实验内排序。顺序、折叠和选择会自动保存。
6. 勾选单个选框、整行蛋白或整个实验，再点击 **“导出原始数据”**。软件进入共用的导出设置页，可选择纸张、方向、每页行数、完整图片／50% 放大、文件名与来源清单，并核对关联的背景图、合成图。
7. 预览后点击导出并选择 PDF 保存位置。返回总览可继续调整勾选；直接打开原始数据导出页时，仍可查看之前保存的统计组合。

总览显示的是**矩形框内部截图**，使用工作台当前保存的对比度、伽马、反相和旋转；点击截图可回到对应图片继续编辑。导出的 PDF 按既有规则显示完整图片或依据选框联动放大三类图像，不会把原文件裁掉。

未画选框的收藏图显示补充提示，失联原图不能导出。实验、蛋白名称未填写时可在总览查看，但需补齐后导出。一次最多 72 个选框、24 个蛋白排版行；同一蛋白每三个选框形成一行，超出时请分批导出。排序与多选不改变原图、泳道测量或统计结果。

## 数据保存、备份与文件移动

- **自动保存**：图片标签、收藏、选框、泳道、内参绑定、图片已应用的分组预设关联及页面设置。
- **手动保存预设**：编辑预设名称、组名和处理方案后，需要点击“保存预设”。
- **手动保存组合**：选定三重复用于复用或导出时，需要点击“保存组合”。
- **备份**：正常关闭软件后，备份整个 `data` 文件夹；原始图片目录也应单独备份。只备份程序目录中的 `data` 不会备份外部原图。
- **迁移电脑**：保留完整程序文件夹、`data` 和原图。重新打开后，对原图的新位置执行添加文件夹或重新扫描。
- **原图移动或改名**：软件通过文件内容校验识别同一图片；在可扫描目录重新找到后可恢复标注关系。它不会自动搜索所有磁盘。
- **原图内容变化**：修改后的文件会被视为新内容，旧测量不能直接套用，须重新核对和测量。
- **分享软件**：使用不含个人 `data` 的发布包；不要把自己的图库数据库和缓存一起发给其他人。

关闭前查看顶部自动保存状态。若提示保存失败，先处理错误再关闭。

## 常见问题

| 情况 | 检查方法 |
|---|---|
| 图片显示为未知日期 | 检查直接父文件夹名称是否包含完整有效年月日 |
| 图片无法定量 | 检查是否为单页、单通道、8/16-bit 灰度图，并查看格式错误说明 |
| 图片黑白方向不符合习惯 | 调整“显示反相”；后台信号极性仍按原始像素值核对 |
| 选中图片后不能生成比较 | 检查目的/内参是否已测量且有效、绑定是否正确、实验/蛋白/组别是否完整，以及每组是否选了至少 3 条有效比值；双条带需先点“计算比值” |
| PDF 中没有某张背景图或合成图 | 检查同目录、相同基础文件名和末尾模式括号；存在多个候选时手工选择 |
| 修改后提示旧测量或旧组合失效 | 按提示重新核对、测量或计算，再保存组合并更新预览 |
| Excel 自动复制失败 | 在软件显示的已选中文本中按 Ctrl+C，再到 Excel 粘贴 |
| 换位置后看不到原来的标注 | 检查是否启动了另一份程序、是否带上原来的 `data`，再重新扫描原图目录 |
| 程序无法启动 | 确认已完整解压、运行目录可写、WebView2 和 .NET 环境可用，并查看 `data/desktop.log` |

## v0.9.3：增量扫描、eBlot 命名与右键删除

重新扫描时，软件会优先比较已登记路径的文件大小、修改时间和文件指纹；未变化的图片直接跳过，只读取新增或发生变化的图片。进度中会分别显示新增或更新、已跳过和失败数量。

新的 eBlot 文件名规则为：M 开头表示背景图，Merge 开头表示合成图，S 开头表示化学发光曝光图；文件名中的 8bit 或 16bit 用于图片类型筛选。实际图像仍会检查容器和位深，命名不会绕过图像格式校验。

在左侧图库右键图片，或右键日期标题，打开删除确认框。日期操作只列出当前筛选下对应日期的图库图片，包括尚未展开或未加载缩略图的部分。确认前核对路径和数量。

默认仅移除图库链接，本地文件保留，也不会被下一次扫描重新加入。选择同时删除本地文件时，软件尝试移入 Windows 回收站；失败项保留链接并提示。其他文件、其他同内容路径副本均不随之删除。日期文件夹仅在已清空后回收。

通过图库中的“恢复链接”可找回标注及绑定记录。如果本地文件已经回收，先在 Windows 回收站还原，再恢复链接并重新扫描。移除内参会使相关目标比值暂不可用，恢复或重新绑定后再统计。

统计页按所选图片和泳道组名识别布局：多图每图每组一个泳道为跨图重复，单图同组至少三个泳道为同膜组内重复。每组至少三个有效样本，超过三个会全部导入。两类布局混合或多图组名不一致时手动核对。请按图片下方的提示检查实验、目的蛋白、内参标签和定量参数；标签未确认一致的不同口径不会自动合并。
