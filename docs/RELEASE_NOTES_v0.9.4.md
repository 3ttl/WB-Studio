# WB Studio v0.9.4

这是相对于 **v0.8.2** 的 Windows 测试版更新，维护者为 Mike Wu。项目源码暂不公开，程序免费提供，采用 PolyForm Strict License 1.0.0 非商业许可。

## 主要更新

### 文件库与图像管理

- 增加收藏标签和收藏总览页面，可按实验、蛋白排列收藏条带并折叠、排序和多选导出。
- 图片类型、文件格式、蛋白名称和实验组别支持多选筛选；统计页和收藏页共用条带文件库。
- 图片支持按直接所在子文件夹的日期分栏、折叠、二级排序和独立滚动；图片信息可单独查看。
- 支持图片或日期分栏右键删除，默认仅移除链接，也可将本地文件移入 Windows 回收站；已移除链接可以恢复。
- 重新扫描改为增量方式：先比较路径、大小和修改时间，未变化的已导入图片直接跳过；新增或变化的图片才重新读取并校验内容指纹。
- 导入进度分别显示新增或更新、已跳过和失败数量。

### eBlot 与 Bio-Rad 图像分类

- 支持 eBlot 命名规则：`M` 开头为背景图，`Merge` 开头为合成图，`S` 开头为化学发光曝光图。
- 文件名中的 `8bit` 或 `16bit` 会用于位深分类和筛选。
- 原有 Bio-Rad 文件名末尾 `Chemiluminescence`、`Composite`、`Amido Black` 等模式分类继续有效。
- 文件名只用于分类，实际格式、页数、通道和像素位深仍会被检查。

### 条带工作台与定量

- 增加实验、蛋白和分组预设的创建、重命名、删除和单选下拉管理。
- 分组预设可以自动展开泳道数和组名，支持一张膜包含多个独立样品的布局。
- 预览框固定 16:9，支持自动聚焦、0.1° 旋转、辅助线、可拖动调整的矩形框、缩放和 Ctrl＋滚轮。
- 所有可预览图片类型均支持按条带位置自动放大，并保持原图周围画面。
- 使用 ImageJ 1.54q 对分析副本进行 8-bit 或原始位深测量；显示对比度、伽马和反相不会改写定量像素。
- 灰度与比值表中增加泳道灰度柱状图，直观显示各泳道信号高低。
- 支持目的蛋白 / 内参比值、双条带比值和多个内参取均值的内参调齐估算。

### 统计与资料导出

- 统计分析自动读取工作台已完成的比值，识别跨图重复和单膜内多个独立样品。
- 支持 Welch t、单因素 ANOVA、配对 t、精确置换检验及平衡独立样本 Two-way ANOVA。
- 可按收藏状态、实验、蛋白和组别筛选，复制结果到 Excel，并保存最终三重复组合。
- 原始数据导出按实验和蛋白整理，生成白底 PDF；每行可呈现化学发光图、背景图和合成图三列，并支持按条带比例放大。
- 导出的曝光图使用工作台保存的显示参数重新生成，PDF 图像统一为 8-bit；统计页仍可导出保留原文件字节的 ZIP。

## 兼容性与数据安全

- v0.8.2 及之后的图库、标签、收藏、矩形框、泳道、内参绑定、统计组合和导出设置会继续保留。
- 软件会为文件位置记录增加修改时间字段，这是索引结构迁移，不会改写原始图片或已有测量值。
- 日期分组继续以图片直接所在子文件夹名称中的日期为准。
- 发布包不包含用户数据库、运行日志或原始实验图片；内置示例为程序生成的 P62 / ACTB 合成图片。

## 下载

普通使用者只需下载 Release 附件中的 `WB_Studio_v0.9.4_Windows_x64.zip`，完整解压后运行 `WB Studio.exe`。同时下载 `SHA256SUMS.txt` 可核对安装包完整性。


## v0.9.4 eBlot 识别修复

- `S-` 开头的 eBlot 曝光图自动建议亮条带极性，减少黑底亮条带被按暗条带处理的问题。
- 对高分辨率 eBlot 图像提高检测像素预算，并增加相邻条带的受约束峰谷分离。
- DPI 仅影响像素采样密度和元数据，不改变原始灰度值；识别仍须人工检查候选框后再定量。
