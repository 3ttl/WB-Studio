# 示例来源与发布包隐私检查

版本：WB Studio v0.9.4，沿用 P62 合成示例。作者：Mike Wu。

## 示例不是实验数据

软件内置 **3 张 P62 目的图和 3 张 ACTB 内参图**，均为程序合成的 TIFF，没有使用真实实验图片。

每图为 600 × 160 像素、单通道 16-bit 灰度。生成脚本先建立灰度值为 60000 的背景，再按预设位置与强度写入四个矩形条带。图像不包含从真实条带复制的像素或文字标签。

v0.8.2 示例修订时，在独立目录重新运行生成脚本，与原有 6 张示例比较，**每个像素及完整 TIFF 文件的 SHA-256 均一致**。后续版本通过逐文件哈希确认示例未变。改成 P62 只调整示例文件名和清单标签，不改变图像像素。P62 在这里仅为示例名称，信号大小与变化方向没有生物学含义。

导入清单没有预置测量结果；使用者点击测量后，由实际 ImageJ 引擎重新读取合成图。已验证 6 张图的导入、24 个泳道信号及内参对应关系。

## 文档图片

工作台、筛选、收藏总览与灰度柱状图截图从隔离的合成图库生成。截图中的八张测试图片由数组、背景及矩形绘制产生，未加载真实图库。另有 WB Studio 标识图片。

## 发布材料检查

- 公开介绍、示例文件名、清单标签、界面提示、压缩界面资源、后端字节码及桌面程序已检查指定课题名称的残留。
- 程序中条带图片限定为上述 6 张可复现的合成 TIFF；其余图像为程序图标、合成界面截图，以及经上游 JAR 校验确认的 ImageJ 自带图形资源。
- 未包含个人图库数据库、SQLite 日志、缓存、缩略图目录、访问令牌文件、真实实验 PDF 或原图导出 ZIP。
- v0.8.2 审计时只读获取本机已索引非示例图片的 SHA-256，与发行包中的图像比较，未发现重合；真实图库的路径、文件名和哈希清单不随发布提供。v0.9.0 检查示例与已验证包一致，新截图仅来自合成图库。
- Java 第三方源码附件与其官方 SHA-256 一致，未向归档追加本机文件。

本说明只针对当前已检查的发布材料；不涵盖以后手动向压缩包加入的内容。向其他人分享时，请使用这里生成的干净程序 ZIP，不要直接压缩自己正在使用、已经含有 data 的程序目录。


## v0.9.1 灰度柱状图修订

v0.9.1 沿用这六张 P62 / ACTB 合成示例；通过逐文件哈希确认示例未变。新增灰度柱状图截图来自程序生成的测试图。最终程序包的文件检查和摘要见同批材料的 VALIDATION.json 与 SHA256SUMS.txt；以上 v0.8.2 审计过程作为示例来源记录保留。


## v0.9.2 图库与统计修订

本次继续使用相同六张合成示例。文件删除验证仅在隔离的合成图库中进行；真实项目的诊断快照、数据库、源文件路径清单与备份均不进入发行目录。未公开的研究名称不用于示例。
