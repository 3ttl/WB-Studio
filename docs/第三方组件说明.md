# WB Studio third-party notices

Internal developer tests use pypdf 6.10.0 for PDF regression checks only. It is not part of the public release; no test dependency archive is distributed. It is not required by, or included in, the ordinary Windows application runtime. Official project: https://github.com/py-pdf/pypdf.

This folder is a local desktop test release. The executable uses the Windows .NET Framework and installed Microsoft Edge WebView2 Evergreen Runtime. It does not install software or bundle a second browser engine.

CPython, NumPy and Pillow were copied from the existing bundled Codex dependency runtime. Their complete supplied license metadata accompanies the private runtime. NumPy wheels include additional components such as OpenBLAS; their license texts are included with NumPy's distribution metadata.

The WebView2 SDK was downloaded directly from Microsoft's official NuGet package endpoint. Its unmanaged x64 loader and .NET Framework 4.6.2 assemblies are redistributed under that package's license. The separately installed WebView2 Evergreen Runtime remains managed by Windows/Microsoft.

PDF dependencies are copied from the supplied local Codex runtime, with package metadata and license texts preserved. PDF export reads an installed Windows font for Chinese text and embeds its subset in the generated document; no Windows font file is redistributed in this application package.

WB Studio bundles an actual ImageJ JAR, the compiled WB Studio bridge class (without bridge source), and a private Java runtime under app/imagej. Exact versions and checksums are recorded in app/imagej/manifest.json; ImageJ notices are in app/imagej/LICENSE-ImageJ.txt and THIRD_PARTY_NOTICES.md, and the Java runtime's supplied legal notices are preserved under app/imagej/runtime/legal. The build-time JDK toolchain is not part of the portable release.


The corresponding Java upstream source archive is supplied as a separate Release asset; see UPSTREAM_SOURCES.md. WB Studio uses its own PolyForm Strict license independently of these third-party terms.
