# v0.9.2：图库删除与重复布局识别

## 图库右键删除

- 在条带工作台或候选图库中，右键图片，选择“删除图片”。右键日期分栏可批量删除当前筛选下这一天的图库图片。
- 确认框列出具体文件、路径、数量和关联影响。默认“仅移除图库链接”，本地文件保留；后续扫描不会自动重新导入。
- 选择“同时删除本地文件”时，使用 Windows 回收站。文件已变化、不可访问或无法回收时保留链接并显示原因；没有永久删除的后备操作。
- 日期分栏可能来自多个真实文件夹。只处理确认清单中的图片，保留未列入的文件；清空后的直接父文件夹可一并回收，不递归删除其他内容。
- 同内容的多个路径共用图像资产。只删除当前显示路径，其他副本保留；因此该图片可能仍出现在图库中。
- “恢复链接”可恢复已移除的图库记录和原有标注。若本地文件已回收，先在 Windows 回收站还原文件，然后恢复链接并重新扫描。

## 自动识别统计重复

- 多张图片、每张每组一个泳道：按跨图重复导入，每张图贡献每组一个比值。
- 单张图片、同组至少三个泳道：按同膜组内重复导入，各泳道分别参与计算。
- 每组至少三个有效样本；四个、五个或更多样本也会全部纳入，不再限制为恰好三条。
- 多图间组别或组内泳道数不一致时，提示手动核对；保留主动取消的样本选择。
- 每张图片下方显示当前统计口径的匹配情况。内参蛋白标签、实验、目的蛋白或定量参数不一致时，明确解释未纳入原因，不静默合并不同来源。

软件识别的是上样布局，独立性仍以实际实验设计为准。同一样本的重复曝光不能增加样本数。生物样本 ID 仍为选填；已填写的重复 ID、配对设计和双因素设计检查继续生效。

ImageJ 测量算法与比值公式不变。统计可选多张图片，论文组合仍保存 1–3 张不同图片。
