# v0.9.3：相对于 v0.8.2 的功能更新

- 重新扫描先比较已登记文件的路径、大小和修改时间；新增或发生变化的文件才读取并校验内容指纹，未变化文件直接跳过。
- 导入进度分别显示新增或更新、已跳过、失败数量。
- 支持 eBlot 命名：M 开头背景图、Merge 开头合成图、S 开头化学发光曝光图；文件名中的 8bit / 16bit 用于类型筛选。
- 继续保留右键删除、恢复链接和每组至少三个样本的统计识别。

本版相对于 v0.8.2 还增加了收藏总览、统计图库和多种导出整理能力；完整的逐项变化见 [v0.9.3 发布说明](RELEASE_NOTES_v0.9.3.md)。

命名规则只用于分类和筛选，实际图像仍会经过格式、页数、通道和像素位深检查。
