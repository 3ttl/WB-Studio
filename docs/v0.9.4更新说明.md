# WB Studio v0.9.4

## eBlot 高分辨率曝光图识别修复

- 识别 eBlot 文件名规则：`S-` 开头的曝光图自动按亮条带处理，`M-` 和 `Merge-` 继续分别识别为背景图和合成图。
- 1200 dpi 图像使用 eBlot 专用识别参数，保留更多像素细节，降低高分辨率缩放导致条带间隙消失的问题。
- 对 eBlot 曝光图中的相邻条带增加受约束的峰谷分离；识别仍只生成候选框，需在工作台确认后再进行 ImageJ 定量。
- 原有 Bio-Rad 通用识别流程保持不变。

### 使用建议

1. 选择 `S-...-8bit-1200dpi.tif` 或 `S-...-16bit-254dpi.tif` 曝光图。
2. 粗略框选包含完整条带的区域，并设置预期泳道数。
3. 点击自动识别后检查候选框；如果曝光区域过大、背景杂乱或条带重叠，请缩小粗选框后再次识别。
4. 候选框确认后再执行测量和统计。

DPI 不是灰度算法的输入，也不会改变原始像素值；1200 dpi 主要表示图像具有更密集的像素采样。本版本针对这种高分辨率数据调整了降采样和 eBlot 条带分离策略。
